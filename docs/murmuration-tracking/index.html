Two passes, one pen change

In Muusia, load Help → Murmuration · Follow one reindeer. Choose ANIMATE → Export order → All frames by pen. Plot all files in pen-00, change ink, then draw pen-02 on the same numbered sheets.

Use fixed paper stops and unchanged origin, scale and orientation. Frame Grid’s Light outlines and numbers stay on the base pen. For 48 A4 sheets set both Frame Grid Total frames and ANIMATE Frames to 48. Never auto-fit the small highlight files in external plotter software.

This study uses the actual Murmuration node. Preview marks are pen paths. The app ZIPs were checked in SVG, G-code and DXF; physical registration still needs a paper trial.
