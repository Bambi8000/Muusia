Try it in Muusia

Download the project, use Load, then select Murmuration. Set ANIMATE → Frames to 36 and press Play. Behaviour is Reindeer herd, with Time source set to Timeline. No extra node is needed.

Choose 24 or 48 frames in Muusia before exporting. The last stored frame leads into the first; the endpoint is not repeated. Frame count is not currently stored in a Muusia project.

A loop you can plot

The same animals keep their identities throughout. Neighbours push apart while followers stay near their moving targets. Preferred spacing is a soft target: a very crowded herd can still overlap.

For green-wire control, choose Manual and connect Frame rot ° → Math ÷ 360 → Time. Keep the seed fixed across the sequence. Preview stroke width is 0.3 mm; the real mark depends on your pen.
