One frame per sheet

Bring the microscope to paper.

  1. Load an example, choose its A4 orientation in the paper presets and select Microbes. Choose Timeline and a moving mode, then set ANIMATE Frames to 24 or 48. Check the complete loop before exporting.
  2. For one numbered A4 sheet per frame, connect the blue Microbes output to Frame Grid. Use Custom 1 × 1, Map canvas, Light outlines and frame numbers. Set Total frames to match ANIMATE, and select Frame Grid as the final output.
  3. For one pen, set Microbes Colours to 1. For several pens, use ANIMATE → Export order → All frames by pen, then export SVG, G-code or DXF. G-code requires your own configured G-code machine profile.
  4. Plot all numbered sheets from the first pen’s folder. Change ink, place each sheet against the same physical paper stops and draw its matching file from the next pen’s folder. Repeat for the remaining pens.

Keep paper size, origin, scale and orientation identical in every pass. Do not auto-fit the smaller colour layers in external plotter software. Light outlines help Liike align photographs afterwards; physical paper stops provide registration while plotting.

Try two sheets first. The node’s geometry and loop have been checked in software; the full physical paper animation is still to be tested. See Murmuration’s pen-pass guide for the numbered-folder workflow and your first physical plot for the initial machine test.
