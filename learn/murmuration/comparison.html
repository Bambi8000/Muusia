One frame per A4 sheet

Two passes, one pen change.

Keep the colour in your animation without changing ink on every sheet. Export all frames for each pen, then run the complete stack twice.

  1. Download the 24-sheet example patch and open it with Muusia’s Load button. It includes Murmuration → Frame Grid, a 297 × 210 mm canvas, Light outlines and frame numbers.
  2. Select Frame Grid. Set ANIMATE Frames to 24. For 48 sheets, set both ANIMATE Frames and Frame Grid Total frames to 48. Animation panel settings are not saved in the patch.
  3. Keep Frame Grid at a Custom 1 × 1 grid and Map canvas. In ANIMATE choose Export order → All frames by pen, then SVG, G-code or DXF. G-code requires a G-code machine profile.
  4. Unzip the export. Plot every numbered file in pen-00 with the base pen. This draws the herd, ground, frame numbers and registration marks.
  5. Change ink once. Put each numbered sheet back against the same physical paper stops and run its matching file from pen-02. This adds only animal 17. Keep origin, scale and orientation unchanged.
Keep the page coordinates

Do not auto-fit or centre the small highlight files in external plotter software. Both passes use the same page coordinates. The ZIP’s manifest lists any empty frames. Each G-code file retains the profile’s start/end, homing and service commands; the files are separate jobs, not an automatic paper feeder.

Try two sheets before drawing the full set. Light outlines help Liike align photographs afterwards; they cannot position paper on the plotter. SVG, G-code and DXF batch exports have been checked in software. Physical two-pass registration has not yet been tested.
