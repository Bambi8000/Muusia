Open the movement in Muusia

  1. Download a project. Save your current work, then choose Load in Muusia and open the .muusia.json file.
  2. Select the last drawing node: its name appears at the end of the example's chain.
  3. Below the preview, set ANIMATE → Frames to the same count as this page (24, 36 or 48), then press ▶ (Play preview).
  4. Export with SVG × 36 (the number follows your frame count). Start with a small plotting test to check pen width and registration.

Muusia does not save the animation frame count in these project files. Set it after loading. The projects keep your current machine profile and set a 140 × 140 mm canvas. Their geometry does not depend on the machine profile.

The join is part of the movement

These examples use existing nodes. Frame's rot ° output is divided by 36 and then by 10 to produce a 0–1 loop phase. This controls the shape's parameters. The viewing angle of the whole drawing stays fixed.

In a 24-frame sequence, the last phase is 23/24. The next phase, 1, matches phase 0, so do not append a duplicate of the first frame. LFO controls back-and-forth movements; seeds stay fixed throughout.

Previews were calculated from the downloadable graphs using Muusia's evaluator. Checks cover 24/36/48 frames, deterministic output, page bounds and the virtual endpoint. Preview lines are simplified by at most 0.06 mm; projects retain full geometry. Distances include pen-down drawing only, not travel or machine time. Browser SVG exports were checked; physical plotting has not yet been tested.
