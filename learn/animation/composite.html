Open it and experiment

  1. Save your current work, then open the downloaded project with Muusia's Load button.
  2. Select the final Merge node to see the complete drawing.
  3. Set ANIMATE → Frames to 36 and press ▶. Counts of 24 and 48 work too.
  4. Export using SVG × 36. Every frame uses the same 140 × 140 mm page.

Set the frame count after loading: Muusia does not yet store it in the project. Your current machine profile is retained.

Both branches read the same Frame node. The background moves 24 mm while the sphere turns 360° during one loop. The last frame continues into the first without a repeated endpoint.

Container's circular cutout is sized for this sphere. If you enlarge the sphere or change its shape, adjust the cutout too. Join mode repeats the last three and first three frames.
